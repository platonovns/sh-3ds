# CIA presentation inputs

These custom SH-3DS resources were approved by the project author for inclusion
in the source release. They are the exact inputs used to reproduce the v0.9.1
HOME Menu presentation; they are not taken from the original game.

| File | Role | SHA-256 |
| --- | --- | --- |
| `icon.png` | Source for HOME Menu SMDH icons and title metadata | `9c14db37c47db5bd2de310803efd4d3b2e708874120c0f436390a7f56b5ecd84` |
| `banner.cgfx` | Pre-converted HOME Menu 3D banner graphics | `c5d72c7be385ccc4550e76437ee2214cb4d8c2dbe4a5b9e8d83720315080bd8b` |
| `banner.wav` | Banner audio passed to bannertool | `32e12d84b63ccf9d6644b6a7106f64aa98c91afaab0a2a97418dc48a2c0a9f39` |

The CGFX is retained as the known-working input: its earlier editable source
and a reproducible conversion pipeline have not been established. SMDH and BNR
are generated by `cia/package.py` and are not inputs to that script. Packaging
also uses `cia/game.rsf`, the newly built ELF, makerom and bannertool.
