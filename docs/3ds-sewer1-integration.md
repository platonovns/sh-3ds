Точное пересечение с diff Block 3: `3ds_port/Makefile.game`, `3ds_port/source/game_map.c`, `3ds_port/source/game_native.c`, `3ds_port/tools/native_overlay.py`. Эти же файлы являются возможными точками конфликта со Stage 11B; точный список Stage 11B должен быть пересчитан по принятому commit при интеграции. Также учитывать общий исходник Hanged Scratcher. Нужно объединить диспетчеризацию resident overlays, списки объектов и инициализацию native animation tables; после разрешения конфликтов заново проверять реальные значения указателей из конечного ELF. `sewer1_sources.mk` добавляет два overlay и таблицы Hanged Scratcher/Groaner. MAP5_S01 подключен как исходный overlay для входа; это не означает прохождение следующей сюжетной линии.

`python3 3ds_port/tools/build_sewer1.py` строит внутренний ELF из объектов проверенного Block 3/Alchemilla и текущих исходников. Нужны devkitARM/devkitPro, замороженные предыдущие объекты и пользовательский оригинальный USA BIN для тестов. Скрипт не делает 3dsx и не публикует его. После интеграции необходимо пересобрать весь конечный проект на принятой базе, повторить source/BIN и callable-table проверки, save/load и реальные состояния, затем отдельно провести аппаратную приемку графики, звука и производительности.

Короткие offline fixtures используют реальные BIN и игровые обновления, но подготавливают состояния напрямую; они не доказывают непрерывный проход или аппаратную корректность. Незавершенные проверки и статус работы изложены в `3ds-sewer1-progress.md`.
